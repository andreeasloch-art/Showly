# Showly

Die Nutzerin prüft Änderungen auf dem Handy. Nach jeder Änderung an der App:

1. Vorschau bauen: `python3 scripts/preview/build.py <Ordner im Scratchpad>`
2. Den Ordner als Artifact veröffentlichen (index.html plus alle Dateien im
   Ordner als `files`). Wenn es schon eine Vorschau gibt, dieselbe URL
   aktualisieren: https://claude.ai/artifact/My7gukq32SCF9QJhFvPjTv
3. In der Antwort immer den Link zur Vorschau mitschicken.

Antworten auf Deutsch.
